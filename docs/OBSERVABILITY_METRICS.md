# 可观测性与指标

Harness 必须同时衡量工程交付质量和投资 Agent 表现。

## 工程指标

- 需求周期时间。
- 每个 sprint 完成的任务数。
- 逃逸缺陷数量。
- CI 通过率。
- 测试覆盖率趋势。
- 发布频率。
- 回滚次数。

## Agent 指标

- 推荐数量。
- 假设复盘完成率。
- 置信度校准误差。
- 被采纳推荐收益。
- 被拒绝推荐的机会成本。
- 用户覆盖 Agent 建议后的成功率。
- 失败模式频率。

## 账户指标

- 总收益。
- 相对基准超额收益。
- 最大回撤。
- 波动率。
- 夏普比率。
- 卡玛比率。
- 胜率。
- 盈亏比。
- 换手率。
- 费用和滑点。

## Skill 指标

- 分周期命中率。
- 分周期超额收益。
- 误报率。
- 最大不利波动。
- 市场 regime 覆盖度。
- 晋升后衰减。
- 回滚率。
