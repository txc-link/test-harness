# ADR-0001：受控离线进化

## 状态

已接受

## 背景

投资 Agent 必须从账户结果、失败假设、用户修正和策略评估中改进。由于投资决策会影响真实资金，Agent 不得自由改写实盘交易规则，也不得在缺少证据时晋升策略或 skill。

## 决策

采用受控离线进化闭环：

```text
运行学习 -> 复盘归因 -> 候选 skill/config 生成 -> backtest -> shadow live -> 人工审批 -> 晋升 -> 回滚监控
```

## 后果

- 运行学习可以更新记忆和示例。
- 高风险策略变化必须通过评估门禁。
- skill 版本只有在可衡量改进后才能晋升。
- 回滚是生命周期的一部分，不是事后补救。
